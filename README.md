## 📌 Sobre o Repositório

Este repositório reúne materiais práticos, guias em PDF e scripts de configuração voltados para a administração de redes e servidores em ambientes virtualizados[cite: 5]. O foco principal é demonstrar a implementação de servidores de endereçamento IP dinâmico (`ISC-DHCP`) integrados a uma interface de administração web intuitiva (`Webmin`)[cite: 5], rodando sob VMs gerenciadas no **Proxmox VE**.

## 📂 Conteúdo e Estrutura

- **`Metodo1.pdf` & `Metodo2.pdf`:** Guias passo a passo detalhando diferentes abordagens e estratégias para a distribuição e mapeamento de IPs na rede.
- **`Comandos e edentações utilizados nos PDFs`:** Documento de apoio contendo os comandos de terminal, sintaxes e edições de arquivos de configuração (`dhcpd.conf`) utilizados nos tutoriais.
- **Integração com Webmin:** Instruções de como monitorar e gerenciar concessões de IP, interfaces e sub-redes diretamente pelo painel web.
